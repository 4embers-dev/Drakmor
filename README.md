# Drakmor
Viduslaiku pārlūka RPG. Spēle: https://4embers-dev.github.io/Drakmor/

## Nākamais posms: konti
1. Izveido Supabase projektu: https://supabase.com/dashboard
2. Atver SQL Editor un izpildi failu `supabase/schema.sql`.
3. Atver Project Settings → API Keys un atrodi **Project URL** un **publishable (anon) key**.
4. Nekad nepublicē `service_role` vai `secret` atslēgu.
5. Authentication → URL Configuration: pievieno `https://4embers-dev.github.io/Drakmor/` pie atļautajiem redirect URL.
6. E-pasta apstiprinājuma un SMTP iestatījumus pielāgo pirms publiskas palaišanas.

Šobrīd 2.0 spēles progress tiek saglabāts tikai pārlūkā. Supabase datubāzes shēma ir sagatavota, bet pieslēgšanās vēl nav aktivizēta. Pirms publiska multiplayer jāizveido servera pārbaudītas cīņas un ekonomika.
